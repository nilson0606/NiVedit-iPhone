1. 新建專案與分類素材

首頁點「新建專案」，輸入名稱並選 16:9 或 9:16，再加入素材。也可以先加入素材，第一次儲存時命名。

點「加入素材」或底部「素材」：影片、圖片主要使用「從相簿選取」，也可選「從『檔案』選取」；音訊從「檔案」加入自己的 MP3、M4A、WAV，或選「NiVedit 內建配樂」。實際選取面板由 iOS 提供；如出現來源選單，選照片圖庫或瀏覽。雲端相簿中的素材需先由系統下載，NiVedit 不會把你的素材上傳到伺服器。

新影片追加到所選影音軌尾端，圖片加入獨立圖片軌，初始長度 5 秒。GIF、標題與字幕仍列在後續階段，尚未開放編輯。頂部可切日夜與繁中／英文，預覽上方可直接切橫直比例。

自己的音檔與 41 首內建配樂

曲庫可分類、搜尋；選取一首才下載，按播放鍵試聽，再按「加入音軌」。沿用桌面版核准的 40 首加範例配樂，不包含被捨棄的新增曲目。音軌可調取用範圍、時間軸位置、音量、靜音、分割及刪除，也會參與預覽與匯出混音。

新增配樂從播放頭開始，預設取用到畫面結束；播放頭已在結尾時從 0 秒加入。影片／圖片決定影片總長，超出畫面長度的音樂不會延長匯出。裁短畫面後，後方音軌仍保留，可移回或刪除。只有音檔時可先試播，需加入圖片或影片才能匯出 MP4。循環、淡入淡出、音量曲線尚待後續移植。

2. 雙影音軌、圖片與留白

影片頂層 L2 優先顯示，遮住影片底層 L1。兩軌原聲仍會相加；畫面被遮住不代表靜音。選取片段後可勾「勾選後靜音」，或調整原聲音量。

點時間軸片段即可選取並定位到開頭。用「時間軸起點」輸入秒數、按「移到播放頭」或「接上一段」移動；也能拖選取片段上的 ⠿ 把手左右移動。要換影音軌，用「軌道」選單。每條軌都可留空白，同一影音軌不可重疊；若位置撞到其他影片，介面會提示並保留原位置。

圖片可以同軌重疊，較晚開始的圖片在前，開始時間相同時維持原有次序。前方圖片結束後，後方仍在播放的圖片會再次顯示；PNG 透明區會露出下方。「圖片疊放」可切到影片上方或下方。

時間軸空白區可左右捲動，內容過高可上下捲動；「縮放」、「符合視窗」、「軌道窗高度」可調整視野。上方播放進度條可精確定位到時間軸任意位置，包括留白。

3. 取用範圍、分割、刪除

「素材起點／終點」決定從原影片取用哪一段，不是時間軸上的擺放時間。可用數字或滑桿調整，兩端至少相差 0.1 秒。圖片也使用這兩個欄位決定停留長度。

先把播放頭放在選取片段內，再按「分割影片」或「分割圖片」。左右兩段各至少保留 0.1 秒，分割後影片接續原素材時間。刪除與縮短不會自動把後面的片段向前補齊，因此留白會保留。↶／↷ 可復原與重做剪輯、位置、分割、刪除及方向設定。

含尚未移植關鍵幀或轉場的桌面片段，暫時不允許分割，以免改壞效果時間；可保留資料存回專案。

4. 存在 iPhone，從同一個入口開啟

一般流程：新建專案 → 命名 → 加入素材／剪輯 → 儲存專案 → 下次從「我的專案」開啟。儲存專案會把編輯資料及原素材一起放在這台 iPhone 的網站本機儲存空間。首頁列最近專案；「開啟專案」或「開啟／管理專案」列出全部。NiVedit 不需要雲端影音伺服器。

「儲存專案」更新目前專案，「另存副本」另建一份。不會自動存草稿；有修改請明確儲存。舊版草稿只會轉成一次性的「先前草稿復原副本」。新建、換專案前若有未存修改，會先提示。

備份到 iPhone「檔案」：在專案管理按「準備 .nvproj 檔案備份」，完成下載或系統分享，才算存到外部檔案。若要只放手機，在系統允許的位置選「我的 iPhone」；選 iCloud Drive 則由 Apple 同步，與 NiVedit 本機專案儲存不同。

要開備份，點「從『檔案』開啟 .nvproj」並自行選取。Web App 不能任意掃描「檔案」或保證記住上次資料夾。從外部開啟後，再按「儲存專案」才會加入「我的專案」，原備份不會自動被覆蓋。

本機專案屬於目前網站及瀏覽器的儲存空間，不會自動出現在「檔案」App。清除網站資料、儲存空間不足或系統清理可能造成遺失；重要專案請另存 .nvproj 備份。持久儲存請求由瀏覽器決定，不能保證永不清理。Safari 分頁與主畫面 Web App 是否共用資料需依裝置確認，請固定從平常的入口使用。

5. 與桌面 V13 互通

手機版讀寫桌面的 NVPROJ1 格式，素材使用 Blob 分段讀取，避免把整個大型專案反覆複製成記憶體陣列。桌面專案裡的標題、字幕、動畫、音樂、效果與未識別欄位會保存於手機專案檔。

目前呈現基礎影片、圖片、原聲與基本獨立音軌。若專案含尚未移植的效果或輸出規格，會顯示提示，並暫停影片匯出以免成品遺漏效果；仍可編輯基本時間及保存 .nvproj。資料互通已驗證，完整視覺與效果互通會隨後續階段補齊。

缺少或無法解碼的素材不會被刪除。點該片段的「重新連結素材」，挑選對應原檔；新檔長度需覆蓋該素材原本取用範圍。尚未補齊時不會匯出缺素材成品或缺素材專案備份。

6. 720p 多軌練習範例

從「開啟／管理專案 → 開啟 720p 範例」開始。範例是本專案自行產生的幾何動畫與輕音測試素材，包含上下影音軌及透明圖片，播放頭從 00:00 開始。

第一次「儲存專案」會要求自己的名稱並建立副本，網站範例不會被覆蓋。修改後可以另存及下載 .nvproj。手機本階段可選 720p／1080p，桌面版可到 4K；範例的 720p 不代表所有真實專案都只能使用 720p。

7. 匯出 MP4 與保存

預覽等待畫面時保留上一張完整畫面；0.2.2 已收到使用者這次播放沒有卡頓的回報；仍持續保留效能診斷。按播放時啟動音訊，不再透過畫面外的影片元素出聲。若預覽長時間沒有回應，會停止並提示重試。裝置診斷可查看畫面更新間隔、音訊狀態與錯誤。

按頂部「匯出」，選橫／直方向與 720p 或 1080p。720p：1280×720 或 720×1280、4 Mbps；1080p：1920×1080 或 1080×1920、8 Mbps。皆為 30 fps、H.264，未靜音的影片原聲與獨立音軌混合成 AAC。

按「開始匯出」，保持畫面在前景。切換 App 或鎖屏會取消作業，可回來重試。匯出會包含時間軸留白、上層遮蓋、透明圖片與雙軌混音。

完成後先試播確認畫面與聲音，再點「分享／儲存到檔案」或「下載 MP4」。是否可直接儲存到照片由系統分享選單決定。編碼完成不等於已存入照片，請到實際保存位置確認。

使用者仍回報 iPhone 偶發匯出失敗，此項依要求先列待修，本次預覽修正不代表偶發匯出問題已解決。重複啟動、取消和清理已有保護；若發生失敗，可保留專案並複製診斷，之後再追查。

8. 更新、離線與診斷

若顯示舊版，從「裝置 → 儲存專案並更新」，或開啟更新工具。先保存需要的成品，再按「更新並重新開啟」。不需要清除網站資料；更新會校驗同一版本的程式檔案，保留已儲存的專案資料。

「裝置 → 複製診斷」提供版本、API、儲存狀態與最近匯出錯誤，重開後仍可查看錯誤。API 顯示支援不等於已通過 iPhone 實機驗收。以 iOS／Safari 26 或更新版本優先驗證。

完整載入應用後可離線開啟已儲存專案及內建小範例。已加入並儲存的配樂包含在專案內；未下載的曲庫音檔仍需網路選取。HEVC、HDR、長片、大檔、低儲存、背景中斷仍需裝置測試。本機驗證優先使用 OPFS 串流成品；無法使用時有記憶體輸出大小限制。

9. 後續階段

第二階段新增的多軌功能仍待你的 iPhone 實機確認。第三階段接著加入大小、位置、透明度、旋轉、矩形／圓形保留內外、兩點關鍵幀、轉場與調色。之後是標題／雙字幕／GIF、進階音軌效果、AI 字幕、相容工具及 4K 全面驗收。最終目標仍為桌面 V13 功能一致。

Quick guide

Create and name a project. Add videos/images from Photos or Files; audio from Files or the 41-track built-in library. New videos append to the selected lower or upper track. Select a clip to edit its source range, timeline start, track, mute and volume. Drag its dotted handle horizontally, or use precise time fields. Video tracks allow gaps; only images overlap on the same track. The upper video is drawn above the lower video, while both original audio tracks are mixed.

My projects opens named local projects with their original media. Open / manage projects provides Save / Save a copy, a project list, .nvproj import, portable backup and a protected 720p example. Download or share the generated .nvproj to retain an external backup. Unknown desktop fields and embedded assets are preserved. Unsupported desktop effects are visibly flagged and block incomplete video export.

Export at 720p or 1080p, keep the app in the foreground, then play and save the result. Intermittent iPhone export failures remain an open issue; phase 2 still requires real-device acceptance. Device diagnostics retain the latest error. Autosave drafts have been removed. Use Save project explicitly. Previous drafts are recovered once into the Projects list. Updates preserve saved projects; clearing site data does not.
