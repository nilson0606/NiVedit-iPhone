- 16 項瀏覽器整合檢查通過；3 項資料模型測試通過。
- 橫向 6 秒來源剪 1–5 秒，成品 4.010667 秒、1280×720 H.264＋AAC。
- 直向來源成品 6.016 秒、720×1280 H.264＋AAC；另驗證具有 90 度 display matrix 的影片。
- 取消後重新匯出成功；草稿重新整理後可恢復媒體與剪輯值；預覽畫格已取像素驗證。
- FFmpeg 獨立解碼：首／中／尾有畫面；音訊有非零取樣，RMS 約 0.1246。這是訊號測試，沒有宣稱由人完成聽感驗收。

## 技術取捨
保留 V13 inP/outP/at/track/proj 等資料語意，未直接載入綁定桌面 DOM 的全域程式。
媒體後端使用固定且自行託管的 Mediabunny 1.58.1，避免桌面 demuxMP4 一次讀入完整 ArrayBuffer，以及全片 OfflineAudioContext 混音的記憶體模式。
此階段只處理單片原聲，無新增合成語意；之後加入多軌時須抽出 V13 合成規則，不能用簡單串接取代。
檔案只在本機處理，沒有後端、API 金鑰或雲端上傳。
Repository 跟網址均獨立，IndexedDB／CacheStorage 命名與桌面分開。GitHub Pages 同一帳號的不同路徑仍是相同 origin，不宣稱為瀏覽器安全隔離。
